Manual de Instruções — AulaPlay (MVP)

Este é um protótipo funcional offline para demonstração na banca. Para usar:

  1. Abra index.html em um navegador moderno.
  2. Clique em Testar Demo para jogar um quiz.
  3. Use as setas do teclado para navegar entre os slides do Pitch (cada seção é uma "slide").

Instalação

  1. Hospede a pasta cafe_codigo_mvp no GitHub Pages ou qualquer serviço estático.
  2. (Opcional) Edite o arquivo data/subjects.json para alterar os conteúdos.

Arquitetura

  • Front-end estático, sem backend (MVP).
  • Plano de integração com IA via APIs (Gemini/AWS Bedrock) e RAG.
