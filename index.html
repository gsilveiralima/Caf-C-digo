AulaPlay MVP

Microaulas gamificadas com IA para EaD — criação rápida de quizzes, flashcards e missões.

O problema

Baixo engajamento, desorganização de estudos e tempo limitado dos docentes para criar atividades personalizadas.

A solução

AulaPlay ajuda professores a gerar microatividades em minutos e entrega aos alunos jornadas curtas com streak, pontos e feedback imediato.

Protótipo & arquitetura (MVP offline)

  • Front-end estático (HTML/CSS/JS) — pronto para hospedar no GitHub Pages.
  • Geração de atividades via IA: integrar com Gemini ou AWS Bedrock no pós-hackathon.
  • RAG para personalizar a partir de PDFs do curso.
  • Guardrails de conteúdo e anonimização de PII.
Demo offline: para a banca, o gerador usa dados locais (data/subjects.json), evitando dependência de APIs.
