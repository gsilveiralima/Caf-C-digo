# AulaPlay — Café & Código

MVP acadêmico desenvolvido para o **Gran Hackathon 2025**, com foco em microaulas gamificadas para educação a distância.

O protótipo é executado inteiramente no navegador com HTML, CSS e JavaScript, permitindo demonstrar o fluxo sem backend ou credenciais externas.

## Demonstração local

Não há instalação de dependências.

1. Clone ou baixe o repositório.
2. Abra `index.html` em um navegador moderno.
3. Use **Testar Demo** para acessar a experiência.
4. O pitch está em `docs/pitch.html`.

## Estrutura

```text
index.html          landing page
demo.html           quiz demonstrativo
css/                estilos
js/                 lógica do protótipo
data/subjects.json  conteúdo de exemplo
docs/pitch.html     apresentação
docs/manual.html    manual
assets/             recursos visuais
```

## O que o MVP demonstra

- navegação de uma experiência de microlearning;
- quiz gamificado;
- separação entre conteúdo e interface;
- prototipação rápida sem dependência de backend;
- material de pitch e documentação associados ao produto.

## Roadmap técnico

Uma evolução do conceito pode incluir:

- geração assistida de questões e feedback com IA;
- RAG sobre materiais didáticos autorizados;
- autenticação/SSO;
- perfis e controle de acesso;
- analytics educacional;
- integração com LMS, Moodle ou Google Classroom;
- testes automatizados e acessibilidade.

## Privacidade

O MVP deve utilizar somente conteúdo demonstrativo. Uma versão com usuários reais precisaria definir coleta mínima, retenção, base legal, autenticação e demais requisitos aplicáveis de proteção de dados.
